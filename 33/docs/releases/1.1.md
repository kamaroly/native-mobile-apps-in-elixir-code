# Risiti 1.1 — First release for testers (October 2026)

Android `versionName` 1.1, `versionCode` 2.

**Needs the Risiti server at risiti.example.com** (Chapter 34's deploy).

## What's new
- Everything: receipts, KRA receipts, refunds and payment requests,
  sign-in, sync and push notifications.

## Installing
- `app-arm64-v8a-release.apk`. If it says "App not installed", use
  `app-armeabi-v7a-release.apk`.
- Uninstall any debug build of Risiti first.

## Checks before handing it out
- Install over the previous version: existing receipts, photos and
  attachments are still there.
- Take a photo, scan a KRA QR code, read a receipt: these go through the
  plugins' bridges, the code R8 must keep.
- Sign in with an SMS code, and with Google.
- Add an expense and check it shows as synced.
